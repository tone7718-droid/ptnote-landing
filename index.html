왜 PT-NOTE인가요

아직도 이렇게 기록하고 계신가요?

치료는 손으로 하는데, 기록은 퇴근 후에. 현장의 불편함에서 시작했습니다.

📋

찾느라 시간 쓰는 종이 차트

서랍 속 차트를 뒤적이다 진료 시간이 밀립니다. 분실되면 기록 자체가 사라집니다.

🌙

퇴근 후 밀린 기록 정리

하루 치료가 끝나고 앉아서 쓰는 기록. 기억에 의존한 기록은 정확도가 떨어집니다.

🔄

인수인계 때 막히는 기록

전임자의 필기체를 해독하느라 시간을 쓰고, 치료 경과 파악이 늦어집니다.

주요 기능

치료실에 맞게 설계했습니다

물리치료 현장의 기록 흐름 그대로. 배울 것 없이 바로 쓸 수 있습니다.

🧍

통증 부위 다이어그램

전면·후면 인체 도표에 통증 부위를 직접 표시합니다. 말로 설명하기 어려운 부위도 한눈에 전달됩니다.

📈

NRS · ROM 추이 그래프

환자별 통증 점수와 관절가동범위 변화를 그래프로 확인합니다. 치료 경과 설명이 쉬워집니다.

⚡

/도수 매크로 자동완성

자주 쓰는 문구를 미리 등록해 두면 /도수 한 번으로 입력됩니다. 반복 기록 시간을 크게 줄여줍니다.

💾

5초 자동 임시 저장

작성 중인 내용은 5초마다 암호화되어 자동 저장됩니다. 갑자기 꺼져도 기록이 날아가지 않습니다.

🖨️

인쇄 · PDF · 백업

기록 인쇄와 PDF 저장은 기본. 전체 데이터는 AES-GCM 암호화 백업으로 안전하게 내보내고 복원합니다.

👥

치료사 계정 관리

치료사 등록과 퇴사 처리, 기록 이관을 지원합니다. master 계정으로 치료실 전체 기록을 관리할 수 있습니다.

보안

환자 정보, 가장 먼저 지킵니다

민감한 환자 기록을 다루는 앱이기에, 보안은 기능이 아니라 전제입니다.

🔐

AES-GCM 암호화 저장

환자 노트와 자동 백업, 임시 저장까지 모두 AES-GCM으로 암호화됩니다. 치료사 비밀번호는 PBKDF2로 안전하게 해시됩니다.

🖥️

OS 보안 저장소에 키 보관

데스크톱 앱의 암호화 키는 Windows 자격 증명 관리자, macOS Keychain 같은 OS 보안 저장소에 보관됩니다.

📦

백업도 암호화

데이터 내보내기 파일은 백업 암호로 암호화됩니다. 평문 내보내기는 경고를 확인한 경우에만 명시적으로 선택할 수 있습니다.

🏠

로컬 우선 설계

로컬 모드는 기기 1대 단독 사용을 전제로 합니다. 클라우드에 올리지 않아도 되는 기록은 기기에만 둡니다.

웹 브라우저 환경의 구조적 한계와 권장 사용법은 앱 내 안내를 참고해 주세요.

시작하기

3단계면 충분합니다

가입 절차도, 복잡한 설정도 없습니다.

1

웹에서 바로 시작

app.ptnote.app에 접속해 관리자 계정을 설정합니다. 설치가 필요 없습니다.

2

환자 등록하고 기록

환자 정보를 입력하고 통증 다이어그램과 ROM을 기록합니다. /도수 매크로로 빠르게 작성하세요.

3

필요하면 데스크톱 앱 설치

치료실 PC에는 Windows 데스크톱 앱을 설치합니다. 새 버전은 자동으로 업데이트됩니다.
